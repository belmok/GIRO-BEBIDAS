# Ícone Giro Bebidas v1

`giro-bebidas-icon-v1.png` é a imagem original gerada por ImageGen, usando a marca Giro Bebidas fornecida pelo usuário como referência. O PNG mantém a transparência. `giro-bebidas-icon-v1.ico` é a conversão para Windows, com imagens RGBA de 16, 24, 32, 48, 64, 128 e 256 pixels. O mesmo ícone identifica aplicativo, instalador e desinstalador.

Ferramenta: ImageGen integrada. Modo: transformação da imagem de referência, fundo transparente. A conversão para ICO não redesenha a imagem.

Prompt utilizado:

Use case: logo-brand. Asset type: ícone de aplicativo Windows para o sistema de vendas Giro Bebidas. A imagem anexada é a marca de referência a ser transformada em um ícone, não deve aparecer como captura de tela. Crie um único ícone quadrado de alta qualidade, visual vetorial limpo e profissional, usando somente o símbolo, sem as palavras GIRO BEBIDAS. Preserve a identidade verde escuro floresta #112D25 e verde menta #B9EAB6 da referência. Um quadrado verde escuro com cantos arredondados, contendo um monograma G menta grande, forte e muito legível; redesenhe o G com uma curva contínua que sugere giro e incorpore uma pequena silhueta simplificada de garrafa no espaço negativo, mantendo o G claramente reconhecível. Estética de software comercial moderno, formas simples e equilibradas, traços largos adequados a ícones 16, 32 e 48 pixels. Composição frontal plana, centralizada, ocupando 90% do quadro, proporção 1:1, bordas nítidas. Apenas um símbolo G, sem texto pequeno, sem marcas extras, sem mockup, sem perspectiva, sem gradientes, sem brilho, sem relevo 3D, sem sombra externa. O fundo fora do quadrado arredondado deve ser realmente transparente, preservando canal alpha.
